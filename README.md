# 🧠 APNEA-ML

Учебная платформа для анализа ночной полисомнографии (ПСГ) и поиска
закономерностей в ЭЭГ, связанных с нарушениями дыхания во сне.

Студенты проходят полный цикл ML-исследования: от скачивания сырых
записей до публикации статьи — через браузер, без программирования.

---

## 🎯 Что внутри

- **311 записей ПСГ** из клиники (2021–2025), 6 каналов ЭЭГ, 200 Гц
- **Спектральные признаки** (δ, θ, α, σ, β, γ) по 6 отведениям —
  126 признаков на эпоху
- **Гибкая разметка** эпох: длина 2–90 сек, порог перекрытия t_pos 0.1–1.0
- **ML-модели**: LogReg, Random Forest, XGBoost, MLP
- **Честная оценка**: split по пациентам, GroupKFold, bootstrap CI
- **HTML-отчёты** с ROC, confusion matrix, SHAP и черновиками разделов
  статьи (Methods, Results)

## 🚀 Быстрый старт

### 1. Установить Python 3.10+
Скачать с [python.org](https://www.python.org/downloads/), при установке
поставить галочку **«Add Python to PATH»**.

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить подключение

Создать в корне проекта `config.ini`:

```ini
[api]
url = https://medllm.ru/psgapp/api/
token = ВАШ_ПЕРСОНАЛЬНЫЙ_ТОКЕН

[paths]
cache_dir = ./data

[limits]
max_speed_mbps = 2.0
max_parallel_downloads = 2
max_retries = 5
```

Токен выдаёт администратор клиники. У каждого пользователя — свой.

### 4. Запустить

```bash
python run.py
```

Откроется `http://localhost:8080` → начните с раздела **«ℹ О проекте»**.

## 📖 Как работать

Пять шагов, каждая страница — подробная инструкция (иконка 📖 вверху):

| Шаг | Страница | Что делаем |
|:---:|----------|------------|
| 1 | ⚙ **Settings** | Проверить подключение к API |
| 2 | **1. Download** | Скачать EDF-файлы (начните с 5–10 пациентов) |
| 3 | **2. Extract** | Превратить EDF в таблицу признаков |
| 4 | **3. Experiments** | Обучить модели, сравнить нормализации |
| 5 | **4. Results** | Открыть HTML-отчёт, скопировать черновики в статью |

**Первый раз — 5–10 пациентов.** Этого хватит, чтобы проверить пайплайн
и увидеть, что все шаги работают. Полный набор (311 записей) — 75 ГБ
и ~10–12 часов загрузки.

## 📚 Что почитать

На странице **«ℹ О проекте»** — 4 вкладки:

- **🎯 О проекте** — что за задача, какие данные, что делает программа
- **📖 Глоссарий** — все термины: клинические, спектральные, ML
- **⚖️ Правила ML** — 10 правил, которые защищают от типичных ошибок

**Обязательно** прочитайте «Правила ML» перед первым экспериментом.

## 🧪 Минимум данных

| Пациентов | Что можно сказать |
|:---------:|-------------------|
| 1–5 | Только проверка, что пайплайн работает |
| 6–15 | Осторожно: «есть сигнал / нет сигнала» |
| **15–30** | **Пилот. Можно обсуждать с научным руководителем** |
| 30–50 | Курсовая / учебная статья |
| **50+** | **Публикация в журнале** |

На 10 пациентах AUC может случайно оказаться 0.9 — это шум, не
результат. После добавления 20+ пациентов цифра упадёт до реалистичной
(0.60–0.75).

## ⚠️ Частые проблемы

| Симптом | Решение |
|---------|---------|
| «401 Unauthorized» | Проверьте токен в ⚙ Settings |
| «429 Too Many Requests» | Подождите 5 минут |
| «Connection loss» в браузере | Операция продолжается в фоне, вернитесь на страницу через минуту |
| «0 эпох» при извлечении | В EDF нет стадий N2/N3, пропустите пациента |
| `ModuleNotFoundError: mne` | `pip install -U mne` |
| Долго грузит EDF | Так задумано (лимит 2 МБ/с, чтобы не перегружать сервер) |

Логи пишутся в `apnea_ml.log` в корне проекта и в разделе **📋 Logs**
в интерфейсе.
